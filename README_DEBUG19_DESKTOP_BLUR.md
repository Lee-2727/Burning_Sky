# Debug19 桌面版轻度云量平滑

直接双击原有的“启动桌面版.bat”进入完整桌面程序，照常查询并打开球面云剖面图；不需要运行独立上海诊断工具。

本版在 burning_sky/spherical_raytrace.py 的 profile_cloud_cells 中对气压层云量采用水平 sigma=10km、垂直 sigma=0.2km 的轻度高斯核平滑。主程序光路检测与桌面剖面图调用同一函数，因此显示和阻挡网格同步。没有模糊云底/云顶几何高度，也不把平滑值当作真实云体边界。云量小于25%的气压层不会作为实体云块，RH>=85%本身不再在云量可用时触发实体墙。

同时修复主光路检测把采样终点以远的矩形部分计入遮挡的问题；多目标光路追踪排除目标所在采样网格，避免云体自身遮挡。注意：这些是实验性近似；目标同网格中真实的上游云可能因此被漏判，不能视为已验证的物理透光概率。

上海案例在当前粗采样下，10km/200m的轻度平滑对多数网格的数值改变很小，这是预期行为；如果仍无有效光线，不代表平滑功能未执行。
