# Debug9：延长球面光路检查与等效云洞地图

本版基于 Debug8，修复球面追踪被 `local_reach`（极限云距）截断的问题：改为检查本次查询已经获得的全部距离采样点，通常至 600 km。**不等于已追踪到太阳**；采样终点之外的大气状况未知，Debug JSON `upstream_unverified: true` 明确标识这一限制。

GUI 在球面追踪成功构建等效云洞时显示 `云洞（等效） 距离 A–B km，大小 C km`，且把等效段标在本地 Debug PNG 上。地图增加随包离线提供的 Natural Earth 概化国界/海岸线轮廓，低/中/高云用蓝/紫/橙半透明采样足迹表示；这是离散采样走廊，不是 Windy 那样的连续 EC/GFS 网格云图。地图不需要在线瓦片服务。

限制：当前光路仍使用太阳方位方向上的一维采样距离，并不为每一分钟重新请求对应太阳方位角的二维云场；云层高度仍采用经验高度带。等效云洞是采样路径上的保守代理，并不能唯一恢复三维云洞的真实形状。由于缺少上游全部云场，`clear_path` 仅代表采样范围内无遮挡，不代表到太阳全程无遮挡。当前版本未重写概率与色彩时序物理模型，不能作为最终物理验证版。
