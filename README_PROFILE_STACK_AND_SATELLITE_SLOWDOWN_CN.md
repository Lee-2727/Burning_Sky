# 网页剖面绘图、垂直叠层目标去重与卫星校准降速

本补丁基于 `V2_2_0` 当前项目结构。

## 1. 网页剖面图

- 将网页 Pillow 粗线绘制替换为桌面融合剖面的 Matplotlib / `LineCollection` 画法。
- 所有已验证云底光路仍保留，但按 15 km 目标区分组，以细线、低透明度绘制，避免数百条粗紫线糊成色块。
- 云锋面严格光路单独以浅紫虚线标注“反烧专用”，不进入常规云底占比。
- 几何候选仍为淡色虚线；红色仅标记严格验证通过的云底采样带。
- 云块和阻挡证据仍按原始剖面绘制；绘图本身不改变算法。

## 2. 垂直堆叠目标去重

- 对同一水平区间内上下相接（容差 0.15 km）的云块，如果下方云块云量达到 25% 光路阻挡阈值，则上方被覆盖的水平部分不再作为独立受光目标。
- 如果只覆盖上方云块的一部分，仅扣除被覆盖部分，未覆盖部分继续分析。
- 下方云块的云底仍按每 15 km、逐分钟验证。
- 所有原始云块仍保留在光路遮挡场和剖面显示中；不会因为目标去重而删除遮挡物。
- 有明显垂直间隔的云层继续作为独立目标。
- 该规则同时用于太阳源距离规划和正式目标光路扫描，不额外增加天气 API 请求。

## 3. 卫星校准降速

- 卫星专用 HTTP 档改为至少 15.5 秒一次、最多 4 次 / 60 秒。
- 共享 HTTP 边界限速，缓存命中不消耗请求额度。
- 任意 Open-Meteo HTTP 429 后，全局暂停至少 20 分钟；若服务端 `Retry-After` 更长则尊重更长时间。
- 已成功下载的补采缓存和进度记录继续保留，可在冷却结束后续跑。
