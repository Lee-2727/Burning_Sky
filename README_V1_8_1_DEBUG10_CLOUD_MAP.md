# Debug10：Windy 风格采样云图（离线测试版）

基于 Debug9，只改桌面 GUI 的「查看朝霞/晚霞地图云层分布」窗口；不修改云洞、概率和色彩时序算法。

新增：低云/中云/高云/综合云量图层切换；半透明连续云色，云量越高颜色越浓；离线 Natural Earth 概化海岸线/国界叠加；现有城市标注和太阳方向；PNG 导出云量覆盖层（透明背景，不包含 Tk 窗口的底图）。

只对空间采样点周边约 30 km 做有界平滑插值，未采样区域透明。不是 Windy 完整二维模式网格或卫星实况。历史缓存若没有 raw_details 空间采样记录，无法重建二维云图。无需新增天气 API 请求。
