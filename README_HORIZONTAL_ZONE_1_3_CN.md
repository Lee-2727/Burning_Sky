# V2.2.0 横向采样区染色比例修订

- 在潜在霞云距内按 15 km 建立水平采样区；不足 15 km 时只设置一个区。
- **有目标中高云的水平区**各算一次，同一水平区多层云不重复计算。
- 逐分钟：某区任一云底采样严格验证受光，记 1；否则，若某区太阳侧云锋面严格验证受光，记 1/3；两种都没有，记 0。
- 每分钟可染色云占比 = 所有目标区计分总和 / 目标区个数 × 100%。最终值取逐分钟峰值，不把不同分钟的有效区取并集。
- 火烧云规模仍沿用现有的霞云距内中高云覆盖率 × 可染色云占比，不乘常规概率。
- 剖面红线只标实际已经验证受光的云底水平采样带的底边；未验证的地方不能标红。
- **云顶**当前没有独立严格验证光路，因此未自动增加 1/3；避免把几何猜测冒充受光事实。
- 单次单模式使用的剖面仍是沿主方向的一维近似；尚未提供三维云体侧面/顶部的完整受光物理模型。
- 本次专项回归 12 项通过。尚未联网测试，不能保证用实况案例的占比会达到特定数值。
