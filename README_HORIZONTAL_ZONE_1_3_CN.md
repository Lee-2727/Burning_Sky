# V2.2.0 横向采样区计量规则（主方向云底版）

- 在潜在霞云距内按 15 km 建立水平采样区；不足 15 km 时只设置一个区。
- **有目标中高云的水平区**各算一次，同一水平区多层云不重复计算。
- 常规朝霞/晚霞是观测者朝太阳方向的逆光视角：逐分钟只统计严格验证的云底受光；受光记 1 区，否则记 0。
- 云锋面、侧面和顶部受光不进入常规火烧云可染色占比、规模、时序峰值或太阳角度色彩评分。
- 太阳反方向的八方位/反烧视角可以单独分析云面或顶部，但必须使用独立受光结果，不能回写常规逆光指标。
- 每分钟可染色云占比 = 云底受光采样区数 / 霞云距内有目标中高云的采样区总数 × 100%。最终值取逐分钟峰值，不把不同分钟的有效区取并集。
- 火烧云规模仍沿用霞云距内中高云覆盖率 × 可染色云占比，不乘常规概率。
- 剖面红线只标实际已经验证受光的云底水平采样带的底边；未验证的地方不能标红。
- 云锋面受光保留为独立证据和剖面图虚线，不再以 1/3 权重混入常规逆光占比。
- 单次单模式使用的剖面仍是沿主方向的一维近似；尚未提供八方位真实三维云体侧面/顶部的完整受光物理模型。
