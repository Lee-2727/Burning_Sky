# V1.8.1 Debug6 — 球面光线追踪诊断增强

基于用户上传的 `V1_8_1_Debug5.zip`。保留原有预测评分与云洞分阶段算法；新增诊断模块默认不参与常规概率评分，避免未经回归校准的几何模型改变业务结果。

## 新增内容
- `burning_sky/spherical_raytrace.py`：球形地球半径下的分钟级太阳位置扫描、沿太阳方位的球面路径采样、光线高度与低/中/高云经验高度带相交检查。
- 单次预测完成后，自动写入本地 `debug_logs/spherical_raytrace_*.json` 和 `debug_logs/spherical_raytrace_map_*.png`。
- JSON逐分钟保存太阳高度角/方位角、各采样点经纬度、距离、光线高度、云量、相交层、遮挡原因及候选清晰窗口。
- PNG绘制采样路径、遮挡点和经纬网格，便于和外部天气云图对照。

## 重要限制
现有输入是模式网格云量与低/中/高云层分类，并非精确三维云体。云层高度带暂用低云0–2 km、中云2–6 km、高云6–12 km；云量阈值≥25%仅作为该网格层的遮挡证据。`clear_or_unresolved`表示没有在采样点命中遮挡条件，不等于真实云洞已证实。

当前PNG为经纬网格示意底图，没有行政区/海岸线矢量底图；路径是球面光路的二维地图投影。新增模块不增加气象API请求。旧的角度交集云洞算法仍保留作为原预测流程，不会被此诊断模块静默替换。

## 验证
`PYTHONPATH=. pytest -q`：原有回归测试与新增球面追踪测试通过。
