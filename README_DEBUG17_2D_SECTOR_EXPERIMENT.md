# Burning Sky V1.8.1 Debug17 — 二维扇形实验版

## 已实现
- 在朝霞、晚霞结果区增加“二维霞云图”按钮。
- 点击时单独请求 120°（太阳方位 ±60°）、潜在霞云距为半径的 8×9=72 个等面积采样区的低中高云量。
- 使用 18 个位置一批，共 4 批；通过现有 request_json 的 URL 缓存机制复用相同请求。注意：72 个位置仍计入 API 用量。
- 两幅图：左侧候选颜色平滑示意；右侧明确分区，每区竖直时间色条，底部早、顶部晚。
- 朝霞只扫描日出前 30 分钟，晚霞只扫描日落后 30 分钟。
- 没有云的网格不着色；不把无数据区填成云。
