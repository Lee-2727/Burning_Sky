# Debug13 — 球面剖面完整曲线与预览验收

- 将 `剖面图` 中的球面光路绘制改为完整采样，不再在第一次超出纵轴范围时永久截断。
- 曲线由 `burning_sky.profile_geometry.sample_ray_curve()` 生成，调用与追踪器一致的 `_ray_height_km()`。
- 浅紫虚线代表数学延长曲线；有效段不允许穿过地球后重新出现。
- 首个模式采样遮挡点仍标记红点，遮挡后的延长部分不是有效太阳光。
- `Burning_Sky_Debug13_Spherical_Profile_Preview.png` 为人工构造云量的球面几何验收图，非真实气象预报截图。
- 固定测试：目标云底 4 km、太阳高度 -1°，最低点 111.195 km、高度 3.029 km，400 km 高度 9.584 km。

## 尚未解决
- 云层仍由离散气压层或低中高云经验高度带估算，尚未实现连续真实云体边界与线段相交。
- 云量是模式网格覆盖率，不等于确定的云体遮挡；颜色深浅不能直接用于严格的二值射线阻挡。
- 气溶胶沿程消光与临界角精确求解尚未接入，不能宣称本版完成第四章算法重构。
- 当前环境不能启动 Windows/Tkinter GUI，PNG 是调用同一球面曲线计算模块的独立渲染验收图。
