V2.2.0 云底采样间距精简修复（2026-11-18）

- 霞云距 0 < R < 15 km：只取一个代表位置 R/2 做云底光追踪。
- R >= 15 km：从观测点 0 km 起按 15 km 间隔取样（0、15、30……），不再额外补不足 15 km 的终点。
- 每个点的覆盖范围按实际长度赋予面积权重，剩余不足 15 km 的区域仍计入计算。
- 极短但独立的云块若落在固定网格之间，保留一个云块中点作为防遗漏检查。
- 删除短霞云距五等份及云底目标的额外自适应二分，减少重复光追踪。
- 保留云前缘检查、太阳几何、远端云遮挡及其他逻辑。未执行在线 API 全链路测试。
