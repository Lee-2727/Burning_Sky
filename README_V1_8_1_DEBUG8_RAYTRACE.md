# Debug8 球面追踪修订（测试版）

- 修复非本地采样点缺少 `layer_data_complete` 导致全部 clear_path 失败。
- 允许太阳高度角为负；通过球面最小半径判断地球遮挡。
- 典型云洞快筛失败后才调用球面追踪；不再启用旧高度角交集。
- 将已确认无遮挡时段中的逐采样层内透明区间提取为空间**等效云洞候选**，不再将 0–极限云距整个光路伪造成云洞。
- 评分阶段移除多个云洞的总长度及数量加分，使用最大候选单洞长度；这是现有评分体系下的过渡实现，尚非逐云洞独立严格几何概率模型。
- 缺失数据与遮挡区分；球面光路数据不完整时不能据此断言真实没有云洞。

## 重要局限（不要将本版当作物理定量校准完成）

现有 EC/GFS 案例大多只保存离散采样云量，缺少逐层云底云顶及逐方位二维云场。球面追踪使用低/中/高云经验高度带，云量阈值是遮挡代理而非精确三维云体。`equivalent_gaps` 是沿采样路径的保守等效区间，不是唯一可逆的真实云洞边界；无法用它严格推出实际光束面积、饱和度或持续时段。旧版云色时序算法保留，尚未完成用户要求的按每条光线严格重新推导颜色、染色面积与时间曲线。要实现这部分，必须补充二维方位采样和云层高度数据并建立可重复的验证案例。
