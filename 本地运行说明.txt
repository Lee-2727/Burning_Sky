Burning Sky V2.0.5 概览更新版 - 本地网页版完整工程

Windows 操作：
1. 安装 Python 3.11 或 3.12，安装时勾选 Add Python to PATH。
2. 双击“安装依赖.bat”，等待安装完成。
3. 双击“启动本地网页版.bat”，浏览器访问 http://localhost:8501。
4. 如需停止，在弹出的命令行窗口按 Ctrl+C。

重要限制：
- 本地网页单次查询可直接使用；联网查询需要 Open-Meteo 服务可用。
- GitHub Actions 自动定时运行只会在 GitHub 仓库执行；在本地启动 Streamlit 不会自动执行 GitHub 的 cron。
- 手动多模概览的远程 GitHub 工作流提交功能可能需要仓库配置及访问凭据；本地运行不等于已具备远程触发权限。
- 本包使用 V2.0.4 完整工程文件补足 V2.0.5 概览更新增量包缺失的文件，随后覆盖 V2.0.5 概览更新文件。缺失的底层算法文件来自 V2.0.4，不能宣称与未提供的完整 V2.0.5 算法逐文件一致。
- 已进行语法编译及 engine 模块导入检查，未完成在线气象 API / GitHub Actions / 全界面交互测试。
