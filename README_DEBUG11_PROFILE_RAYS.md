# Debug11：剖面图 + 球面光路
- 桌面 GUI 的「高度剖面」按钮更名为「剖面图」，显示低/中/高云剖面灰阶（云量 0–100% 色条）。
- 叠加球面几何光路：使用 burning_sky.spherical_raytrace._ray_height_km，与追踪器相同的球面高度公式；可呈 U 形，允许负太阳高度角。
- 如果当前查询生成了 spherical_raytrace_debug_json，选取最多 9 个实际时刻绘制；绿色为采样范围内 clear_path，红色为 blocked（在首遮挡点停止并标红点），紫色为未证实。
- 快筛跳过追踪时，依据事件时间和太阳位置绘制几何示意曲线，紫色表示尚未做遮挡验证。
- 历史案例缺少云底时用 4km 仅作示意并明确提示；没有气压剖面时仍沿用原有分层高度带近似。
- 不修改概率、云洞、色彩时序等预测算法，也不增加 API 请求。
- 注意：云量不等于实体云边界；仅凭灰阶矩形与光线视觉重合不能代替原算法的遮挡判断。光路只覆盖已采样距离。
