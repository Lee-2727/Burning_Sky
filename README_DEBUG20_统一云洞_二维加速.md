# Debug20：统一云洞候选与二维加速（桌面实验版）

- 常规分析优先使用极限云距内明确云洞；若无明确云洞，调用一维气压层多目标自适应光路搜索，寻找等效透光区间。
- 自适应搜索：在日出前/日落后30分钟内粗扫3分钟，状态变化附近二分，双端同态区间也探查中点；在采样范围内按目标距离单元合并多个候选通道，截断至极限云距。
- 云剖面沿用 Debug19 的10km/200m轻度云量平滑。经验风险<0.7是实验阈值，不能视为真实光线透过概率。缺失数据不伪造晴空。
- 通道列表供原有常规评分及峰值云色共用；无候选且数据可评估时常规评分归零，数据不足或异常仍为保守上限。
- 二维图中心0°方向复用常规查询样本，侧向只请求左右各3个点（共6点），批量请求并复用原有磁盘缓存；窗口显示阶段及持续耗时。
- 二维图侧向仍只有低/中/高云量和参考高度，没有完整三维云体及侧向气压层；不能当作已验证的真实受光面积或正式霞云规模。
