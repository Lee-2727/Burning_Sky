# 火烧云预报工具 v1.4.62（绝对云底海拔与案例海拔保存修正）

## 文件
- `app.py`：Streamlit 网页界面，支持地名联想、坐标与海拔输入。
- `engine.py`：v1.4.62 计算引擎。
- `china_city_coordinates.xlsx`：地点坐标及近似海拔，可继续补充垭口/山峰。
- `desktop/fire_cloud_forecast_v1_4_62_elevation_diagnostics.py`：对应桌面 Tkinter 脚本。
- `requirements.txt`：运行依赖。

## 本次修改
- 云底统一明确区分离地高度 AGL 与海拔绝对高度 ASL。
- 天气剖面估算先得到相对当地地面的云底高度，再加观测地点海拔，转为绝对高度参与几何计算。
- 手动云底高度/回退值现按海拔绝对高度输入（km）。在海拔 0 m 时与原有数值一致。
- 实况模拟 Excel 的“基本信息”新增/支持 `海拔_m` 字段；旧模板缺少该字段时默认 0 m。
- 单次模式导出的实况模拟 Excel 自动保存当前机位海拔；实况模拟报告会记录观测点海拔，并把“云层区间”的高度范围按海拔绝对高度 ASL 解释。
- 保存案例时将 `elevation_m` 以数值保存，加载案例时恢复；加载历史案例不触发天气请求。
- 保留原有云洞、晴空间隔、云距、霞距与评分计算链；新增的海拔处理只在需要转换云底高度基准时介入。

## 实况模拟 Excel
“基本信息”工作表使用两列：字段、值。可以加入：
- `海拔_m`：观测点海拔，单位米；省略时默认 0。

“云层区间”工作表的 `云高度范围_m` 按绝对海拔填写，例如 `1200~2500米` 表示云底/云顶海拔区间约为 1200–2500 m ASL，而不是离地高度。请按该基准填写所有云层范围。

## 部署
1. 将 ZIP 解压后上传所有文件到 GitHub 仓库。
2. 在 Streamlit Community Cloud 选择仓库和 `app.py` 部署。
3. 先用 0 m 海拔测试，再用已知高海拔地点测试。

## 限制与测试说明
- 云底来自数值天气模式剖面启发式推算，不是实测云底。
- 经验评分不是经历史观测校准的统计概率。
- 已进行 Python 语法编译与核心高度换算模拟测试；尚未完成 Windows GUI、真实天气 API 和云端端到端测试。


## v1.4.62 实况模拟海拔过滤修正
- 实况模拟 Excel 的云层高度范围按绝对海拔 ASL 解释。
- 观测点海拔大于 0 时，仅对 0–80 km 内低于机位的云层进行过滤；跨越机位高度的云层只保留机位以上部分。
- 80 km 外云层保留，继续进入原有云洞、距离、评分与动态光路计算。
- 过滤诊断会写入实况模拟分析报告。
- 同一距离段多行表示不同高度层时，采样会合并所有高度层，避免只读取第一行；起点云底采用起点处有效云层的最低云底。
- 海拔 0 m 时不启用新增过滤。


## v1.4.62 实况 Excel 海拔读取与诊断
- 读取“基本信息”时，兼容“字段/值”逐行布局，也兼容第一行字段名、第二行对应值的布局。
- 海拔字段兼容 `海拔_m`、`观测点海拔_m`、`海拔（m）` 和 `海拔`。
- 报告同时显示过滤前后低/中/高高度带的加权云量、观测点海拔、过滤高度层数量和过滤范围，便于核实 Excel 海拔是否生效。
- 单次单模式结果不再重复追加 `| 模式起报：...`。
- 概率评分沿用原有分段评分，不会为了制造分数变化而改动评分权重；若过滤前后仍处于同一评分档位，最终整数分数可能相同，但诊断中的高度带云量应能显示差异。


## v1.4.64 高海拔云层处理

- 所有云层高度均按绝对海拔 ASL 解释。
- 若 0–80 km 本地参考云底高于机位，完整沿用原算法。
- 若机位高于本地参考云底，先仅用 0–80 km 高于机位的云层重估新云底和理论极限云距。
- 仅当新极限云距内、80 km 以外存在明确云洞证据（云量不高于 15%、交集宽度至少 15 km，且云洞两侧有云区证据）时，才移除所有低于机位的云层并重新评分；否则回退原始 0 m 算法。
- 实况模拟报告会写出原始云底、新云底、新极限云距和云洞判定。该逻辑是对人工区间输入的启发式几何判定，仍需用用户的真实 Excel 案例验证。

## v1.4.66 本地烧云规模评估

- 保留沿太阳方向原有 15 km 半径空间采样及原有发生/色彩评分算法。
- 另在查询点中心及 20 km、40 km 两个环上的 8 个方位点进行独立本地云量采样，仅用于烧云规模标签。
- 烧云规模参考指数：max(本地中云量, 本地高云量) − 本地低云量，结果下限为 0，再乘以可染色云量占比。
- 判读显示为“概率等级 + 色彩等级 + 烧云规模”，色彩等级使用淡黄、金、橘、红、红紫逐级区分。
- 该规模指数属于经验参考值，尚未经过历史实况校准。
