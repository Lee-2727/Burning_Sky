# Burning Sky

Pro、Lite 和 Windows 桌面端共用预测引擎。

| 客户端 | 启动方式 |
|---|---|
| Pro | `streamlit run app.py` |
| Lite | `streamlit run lite/app.py` |
| Windows 桌面版 | 双击「启动桌面版.bat」 |

网页端先运行 `pip install -r requirements.txt`。部署时为 Pro 和 Lite 分别指定入口。更新已有仓库时，保留自行维护的配置和已经发布的概览数据。
