Burning Sky V1.0.0 - 远端低云经验封顶取消（累计太阳角度修复）

本补丁以 Solar Azimuth FIX 为基础，累计包含此前网页版/桌面版评分一致性、严格1.3x光路验证、逐分钟真实太阳方位角/15km采样带空间覆盖检查。

修复：
- 远端沿途“连续低云>=90%、连续>=30km -> 常规概率封顶12%”等纯云量宽度经验规则不再更改概率、色彩评分与峰值云色色块；无论是否存在远端低云，是否遮挡以逐分钟球面光路与相交云层判定为准。
- 本地低云>=85%/95%仍按原本地视野约束处理；本地低云>=90%、云底过低、光板天及严格主光路门槛保留。
- 诊断字段 remote_low_cloud_screen_disabled=True、ignored_remote_low_cloud_runs 记录被忽略的远端候选屏障段数。
- 原先加载案例仅恢复保存结果，不会自动重新计算概率；如要看到修复后的结果，请选择原始请求缓存重新查询，或联网查询。

验证：2026-11-10合肥GFS朝霞原始请求缓存离线复算：常规概率由12%变为72%，可染色云占比保持34.7%，可验证候选光路16分钟（06:19至06:34左右）。该72%仅为现有模型经验估计，不是经过校准的客观频率。

安装：按补丁目录结构覆盖原项目中的 app.py、engine.py、burning_sky/algorithm.py、burning_sky/sky_six.py，不覆盖data/。无需叠加旧补丁。
