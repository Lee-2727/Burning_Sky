# Debug16: 压力层几何一致性与朝晚时间限制

- 修复：原先光路遮挡检测使用低云0–2km/中云2–6km/高云6–12km固定高度带，但GUI云块用气压层剖面；现有剖面时，检测与绘图均使用同一套气压层云块矩形边界。
- 光线连续检查矩形距离区间（含球面最低点），而非仅在离散采样点检查。
- 朝霞严格只扫描日出前30分钟至日出时刻；晚霞严格只扫描日落时刻至日落后30分钟。**不再将日出后、日落前用于火烧云光路判定。**
- 案例验证：2026-11-03 宁波 EC，目标云底3.61km：旧固定高度带在31个日出前时刻全部判为blocked；新压力层云块法得到日出前约06:05:38–06:08:38四个连续分钟采样候选clear_path。注意仅确认0–450km的已保存压力层数据，450km以远未验证。
- 仍存在：气压层云量不是实心云体，二维中心线无法唯一确定云洞；气压层之间云体厚度采用与GUI一致的中点矩形近似；没有验证连续角度之间的全部光路；不能将此结果当成精确概率。
