# Burning Sky · 几何规模与视觉规模

## 1. 两种规模分别回答什么

- **几何规模**：整个朝霞/晚霞有效窗口内，曾经通过严格云底受光验证的唯一 15 km 水平采样区，占霞云距内全部唯一目标采样区的比例，再乘本地霞云距内中高云资源量。
- **视觉规模**：使用同一批“整个窗口内曾经受光”的唯一采样区，但按其从观测点看见的球面视角面积加权，再乘同一份本地中高云资源量。

两者不乘常规概率。常规概率仍是独立指标。

## 2. 统一的目标采样区

1. 霞云距内沿太阳方向每 15 km 划分一个水平采样区；霞云距不足 15 km 时仍只建立一个区。
2. 同一水平位置出现上下堆叠云层时，按现有 `one_lowest_cloud_target_per_vertical_column` 规则只保留一个目标云层。上层云仍保留在完整云场中作为太阳光路遮挡物，但不作为第二个目标区域重复计数。
3. 标准朝霞/晚霞仍然只以严格验证通过的**云底**作为受光证据；云顶、侧面和云锋面不增加常规受光占比。
4. 分子、分母使用完全相同的唯一水平采样区集合。

## 3. 整个事件窗口累计

对每个唯一采样区，只要朝霞日出前或晚霞日落后的有效分钟窗口内，至少有一分钟的云底通过严格球面光路验证，该区就记为“曾经受光”，整个事件只计一次。

这与云色时序的逐分钟占比不同：时序仍按每分钟计算；几何/视觉规模使用整个事件窗口的累计区域集合。

## 4. 几何规模

设目标区总数为 `N`，整个事件窗口内曾经严格受光的唯一目标区数为 `L`：

`几何可染色占比 = L / N × 100%`

`几何规模 = 本地霞云距内中高云资源量 × 几何可染色占比 / 100`

本地中高云资源量沿用现有 `potential_range_mid_high_pct`，不更改其数据来源和计算口径。

## 5. 视觉视角面积

当前剖面是沿太阳方位的一维中心线，不包含真实二维云块边界。因此先构造一个明确标注的**等效云块视角面积模型**：

1. 对每个 15 km 目标区，按目标云覆盖率与其在该区内的水平长度，估算该区的等效水平覆盖面积。
2. 将等效覆盖面积转换为一个紧凑等效云块；径向长度和横向宽度按覆盖面积比例的平方根缩放。横向基础宽度暂按一个 15 km 采样宽度。
3. 使用目标云底、云顶的代表高度，以及等效云块距观测点的近远边界，将云块角点投影到方位角/视高度坐标。
4. 视高度采用球面地球表观高度角，而不是平面地球近似；在 `(方位角, sin(视高度))` 平面求投影凸包面积。该平面面积对应球面立体角，单位为 sr。
5. 每个唯一目标区得到一个视角面积权重 `Ωᵢ`。

`视觉可染色占比 = 曾经受光目标区的 Ωᵢ 之和 / 全部目标区的 Ωᵢ 之和 × 100%`

`视觉规模 = 本地霞云距内中高云资源量 × 视觉可染色占比 / 100`

因此，同样物理大小的近处云会有更大的视角面积权重；远处云的权重自然减小。视觉权重不参与光路通过/遮挡判定，也不会让云顶或侧面变成受光证据。

## 6. 输出字段与兼容

- `tintable_ratio` / `geometric_tintable_ratio`：整个事件窗口累计几何可染色占比。
- `visual_tintable_ratio`：整个事件窗口累计视觉可染色占比。
- `geometric_burn_scale_index`：几何规模。
- `visual_burn_scale_index`：视觉规模。
- `burn_scale_index`：为兼容旧缓存和调用方，继续等于几何规模。

云色时序仍保留逐分钟受光曲线，不用事件累计比例替代每分钟曲线。

## 7. 模型边界

视觉模型是基于现有一维剖面的投影视角面积代理，不是卫星反演的真实三维云体。横向宽度按 15 km 采样宽度近似，云块覆盖面积由云量比例构造，云层高度来自现有气压层剖面。后续如果接入可靠的二维云场，可将等效横向宽度替换为实际云块边界；当前版本不会为此增加天气 API 请求。

## 8. 网页主显示的视觉规模分级

网页主显示以 `visual_burn_scale_index` 为准，几何规模只在 Pro 的辅助信息中查看：

- 低于 3%：不烧
- 3%–15%：微烧
- 15%–40%：小烧
- 40%–65%：中烧
- 65%–90%：大烧
- 高于 90%–100%：世纪大烧

边界值归入较低一级区间（例如 15% 为微烧、40% 为小烧、90% 为大烧）。色彩分仍是独立的大气色彩质量分，不存在单独的几何色彩分。
