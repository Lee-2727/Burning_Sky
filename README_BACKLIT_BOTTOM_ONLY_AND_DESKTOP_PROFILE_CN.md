# 常规逆光云底受光与网页桌面风格剖面图修正

## 1. 常规火烧云（朝霞/晚霞）

- 正式可染色占比只统计霞云距内 15 km 横向目标区的严格云底受光。
- 每个采样区独立、逐分钟验证；云底验证通过计 1 区。
- 云锋面/侧面/顶部受光记录保留为独立诊断，不进入常规逆光可染色占比、规模、峰值时序或色彩角度评分。
- 完整采样且没有任何云底通过时，常规主光路按无本地云底受光处理；存在 unresolved 时仍然保留未知，不伪造 0。
- `tintable_ratio_diagnostic` 改为从逐分钟实际记录动态生成，分别列出云底受光区、云锋面诊断区、阻挡与未验证数，不再写死“云底受光 1 区”。

## 2. 八方位/反烧

太阳反方向的观测视角可以独立考虑朝向观测者的云面和顶部，但不能回写常规火烧云指标。当前 `compass_illuminated_sectors` 仍是二维 OM 云场候选优势图，不是完整的侧面/顶部三维严格受光计算；不能把候选优势说成已验证的反烧面积。

## 3. 网页剖面图

`burning_sky/profile_image.py` 已按桌面诊断图的画法重绘：

- 使用与光追踪相同的云层采样单元；
- 灰阶云块、重构云层虚线边界、云底点；
- 严格验证的云底光线使用紫色实线，红色底边表示已验证受光的云底采样条；
- 严格验证的云锋面光线使用另一种紫色虚线，并标注“反烧专用，不计入常规逆光占比”；
- 未验证几何候选、云阻挡、地球/地平线阻挡、OM 冲突分别显示，不混成正式受光光线；
- 保留霞云范围、云边界和云量灰阶图例。

网页调用入口仍为 `app.py::_web_profile_figure()`，无需更改 Streamlit 页面调用。

## 4. 主要修改文件

- `burning_sky/local_cloud_illumination.py`：常规默认 bottom-only；`include_faces=True` 仅为独立反烧调用预留。
- `engine.py`：主路径门控、完整云底扫描判断、诊断信息与面光证据分离；保存 `verified_sunward_face_bands`。
- `burning_sky/algorithm.py`：常规色彩太阳角度评分只取严格验证云底角度。
- `burning_sky/profile_image.py`：网页剖面图使用桌面风格。

## 5. 验证

新增/更新的离线测试覆盖：默认面光不计入、显式面光模式仍可独立启用、色彩角度评分不接收面光、网页剖面图渲染。

注意：当前八方位模块尚未接入侧面/顶部的完整三维严格受光验证。
