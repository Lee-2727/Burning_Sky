# Debug19 上海光路实验（离线诊断）

双击运行 `上海光路自适应测试.py`（需 Python 和原项目依赖），选择已保存的上海案例 ZIP，点击“开始离线测试”。读取案例原始气压层，不请求天气 API；窗口显示计算状态，完成后写出 JSON。

这是 Debug18 基础上的**独立实验入口**，不修改主预测的常规概率、云色和二维图计算，以免把未校准的遮挡风险直接投入正式评分。对比原始云量、10km/200m、20km/400m 三种核平滑；太阳角度随真实时间变化，临界时间区间自适应细分至约 0.05 分钟。经验风险值并非物理透射率；目标云自身前1km排除，尚不代表真实云体前缘精确位置。此版本没有解决二维图的请求速度问题。
