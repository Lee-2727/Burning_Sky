# V2.2.0 云底全霞云距 15 km 扫描修复

- 单次单模式：目标取点从 0 km 开始，每 15 km 到霞云距，并包含末端。
- 当霞云距 <75 km 时，使用 5 等份（6 个节点，包括本地及末端）。
- 在实际有中、高云的段落计算云底受光；没有目标云的节点不算面积，但仍用于上游云场遮挡判断。
- 短云块如果落在两个全局采样节点之间，补一个云块中点，防止完全漏检。
- 有效/遮挡/数据不明状态改变的相邻节点间，最多三轮二分，逼近临界位置，不把未验证当成无遮挡。
- 每个采样点根据代表的实际区间长度参与染色占比及加权太阳角度，不能把总面积除以固定 9 点。
- 每条光线仍独立验证球面地球遮挡、真实云层遮挡、动态上游距离及实际可用气压层。云锋面另算，不替代云底。
- 不改变 Web 页面、概率规则与云色计算公式；本补丁不提供新的线上 Open-Meteo 验证。

## 安装
完整包：解压 `V2_2_0/` 后用 `START_GFS_OM_DESKTOP_DEBUG.bat`。
补丁：将 `burning_sky/sky_six.py` 与 `burning_sky/local_cloud_illumination.py` 覆盖到当前 V2.2.0 对应位置。不要覆盖 data。

## 验证
专项 20 项通过。全量运行 146 通过、29 失败；其中 2 项旧 `test_solar_offaxis_resample` 断言仍坚持“只看远端云锋面，不能本地云底通过”的旧假设，改动后不再成立。其余失败为项目既有概览/评分/联网断言。尚未取得包含全部动态上游新采样的线上正式预测结果；不能宣称完整预测已验证。
