# Burning Sky V1.8.1 Debug14 — 视野扇形与有效光束填充试验

## 已实现
- GUI 剖面图在相邻一分钟均判定为 `clear_path` 的两条球面光线之间绘制紫红色散点；严格在两条曲线之间，不填充下方。
- 若某一分钟 `blocked` / `unresolved_data`，则不跨越该时刻填充。
- 显示视野扇形建议：太阳方位±15°、近景30km细采样、远景按云层可见性可扩展至约300–350km。

## 重要限制
- 当前仅有中心线采样数据，不能把一维剖面伪称为真实30°扇形云图。
- 两条相邻采样光线均无遮挡不保证两者之间所有连续角度无遮挡；紫红点是候选区域，不是严格连续证明。
- 旧 `clear_path` 仅表示已采样路径未发现阻挡，未验证更远上游；分层云量使用近似高度带和25%阈值。
- 尚未修改常规概率、云色时序、峰值云色或可染色占比；需要真正二维扇形网格和多目标光线追踪后再接入。
- GUI 未在 Windows 运行实测。请先用已有查询数据打开剖面图测试。

## 后续计算建议
- 30°扇形：太阳方位左右各15°；径向0–30km加密，30km以外依云层可见高度延伸。
- 以观察者视线的立体角（方位角×仰角）而非地面面积计权，避免远距离面积不合理放大；云层高度、可见性和前景遮挡需分别处理。
- 先实现真正的二维扇形采样和逐目标受光，再把结果接入可染色占比与概率。
