# V2.2.0 色彩评分与横向受光区同步修复

基线：V2.2.0 Horizontal_Zones_OneThird 完整桌面包。

修改：
- 色彩质量分数仅由大气 AOD、能见度等光学条件估算；中高云面积、总云量、云洞数量、低云量不再对色彩质量直接加减分。这些因素仍由独立的概率、可染色占比、规模与可见性规则负责。
- 常规朝霞/晚霞的峰值参考分钟改为 **严格验证的云底采样区**逐分钟占比最高的时刻；云锋面、侧面和顶部不参与常规逆光色彩角度评分。
- 有效太阳角度深度和跨度只从严格验证的云底受光记录中提取；没有云底受光，不得用云锋面角度补分。
- CAMS 垂直修正保留诊断记录，不再在已按 AOD 评分的色彩分上重复乘系数。云色时序自身的物理经验衰减本次不动。
- 标签统一：平平(0–29)、普通(30–49)、绚烂(50–69)、史诗(70–89)、世纪(90–100)。
- 完整验证且没有云底受光时记0；受光证据不足时不作确定性色彩评分。

不修改：云底/云锋面球面光追踪本身、15km云底采样、常规概率公式、规模公式和云色色板。云锋面光路仍保留为独立的反烧诊断证据。
