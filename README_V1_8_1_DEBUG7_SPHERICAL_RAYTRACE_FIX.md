# Burning Sky V1.8.1 Debug7 — 球面透光判定修复

基于 Debug6 球面光线追踪版。

## 判定流程
1. 在理论极限云距内先进行直接晴空区快筛（低/中/高云量均需有数据且≤15%）。
2. 若快筛找到有效晴空区，采用该候选结果，不调用球面追踪。
3. 若快筛未找到晴空区，启动分钟级球面地球光线追踪；旧高度角区间求交集算法已从云洞搜索中移除，不再产生“云隙透光”判定。
4. 球面追踪只有在路径采样数据完整且未命中遮挡阈值时，才认可无遮挡时段。无有效路径或追踪失败时，按无有效透光路径保守处理：常规概率≤20%，上限概率≤35%。
5. Debug JSON记录每分钟状态、光线高度、各采样点云量、遮挡点、候选无遮挡窗口及状态计数；无新增气象 API 请求。

## 近似模型说明
云量来自模式网格，低/中/高云分别采用0–2、2–6、6–12 km经验高度带，云量阈值≥25%作为层内遮挡代理。它不是精确三维云体或云边界。
