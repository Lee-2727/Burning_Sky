# Burning Sky Debug18 六分区天空图 + 多目标光路诊断

## 已实现
- 观察者视角，太阳方向左右各60度，仰角0-90度，3列×2行共6个显示分区。
- 点击「二维霞云图」立即出现六分区空图，不再等待网络完成后才开图。
- 最多查询9个真实空间位置（-40/0/+40度 × 霞云距25%/55%/85%），优先命中原有请求缓存；网络失败保留空图并显示错误。
- 左侧分区内平滑候选云色，右侧每区竖直时序色条。
- 朝霞严格使用日出前，晚霞严格使用日落后。
- 增加沿中心线0～霞云距多个实际气压层高度的独立太阳光路诊断，结果记录到 debug_logs/spherical_raytrace_*.json 中 multi_target_diagnostic。

## 重要限制（请先读）
- 这版并非完整修复上海案例：上海离线回归中8个候选气压层目标均未通过当前保守的连续云块遮挡测试；不能把此结果视为已经证明远端云不受光。
- 9个二维采样点只获取低/中/高云量；侧向没有气压层云高及连续上游光路。因此六分区颜色仅为候选可见云色，不能代表真实受光结果。
- 当前正式霞云规模、可染色云占比、概率和原剖面图仍采用旧逻辑，未用候选结果替换。
- 由于六分区不是六个地面网格，不应把候选分区数除以6直接当作物理受光面积。
- 没有在Windows Tkinter环境下实机测试，网络 API 也未在本环境中请求。
