Burning Sky V1.0.0 — 逐分钟太阳方位变化 / 严格空间覆盖门槛修复

本补丁累计包含先前的网页/桌面概率一致性与1.3倍上游光路修复。

本轮改动：
1. 云层目标位置固定在事件（当地日出/日落）方位的原始采样轴线上，不再每分钟随太阳方位漂移。
2. 每分钟在固定目标的实际地理坐标重新求太阳高度角与方位角，从目标向太阳方向投影光路。
3. 每隔不超过10km比较投影光路与原始一维剖面采样轴的球面距离，超过15km采样带则不能判定该目标当分钟光路已验证；不以剖面外未知云况当晴空。
4. 保留原来的气压层遮挡、目标云向阳面、球面曲率和1.3倍极限云距检查。
5. 诊断新增 spatially_unverified_minutes / spatial_coverage_diagnostics / solar_azimuth_deg / profile_max_lateral_offset_km。
6. 只使用已有离线采样数据；此版本没有新增二维云场联网请求。15km仅为原有邻域采样带的近似，不是连续二维云场的严格认证。

使用方式：将补丁zip中的 app.py / engine.py / burning_sky/algorithm.py / burning_sky/sky_six.py 依目录覆盖到原项目根目录即可。
不要清理/覆盖 data/。桌面与Web共享 engine.py 和 sky_six.py。

离线验证：2026-11-10合肥 GFS 朝霞，旧版全部31分钟通过，新增方位覆盖后仅偏移[-15,0]的16分钟有被确认的候选受光路径；常规概率12%，可染色云占比34.7%，与前一版40.4%不同。未通过空间覆盖的时刻为未验证，而非确证遮挡。不同缓存和模型更新时间可能导致概率差异。
